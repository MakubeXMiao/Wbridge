## 固定输入与实现

采用 d8188f687131a069deb86a8678226766245c1421 的 `docs/lines/01-core/INBOX-MEDIA-DIAGNOSTICS-V1.md` 契约。`media_diagnostics` 只提供有界的本地下载来源、实际读取字节数、结果及固定原因，不包含 URL、钥匙、原体、路径、账号、context、正文或异常原文。

1.1 `hooks/muse-worker.py` 在既有 `_snapshot` 内独立净化这个可选字段，统一用于 begin、refresh 和 needs_refresh。只检查确认过的属性，不遍历未知敏感子树；摘要仅由净化后的消息计算，私有会话不保存消息体或诊断对象。

1.2 坏容器、未知版本或容器属性类型错误时丢弃整个诊断。坏子项、同附件重复来源、第三个来源或超额子项被丢弃并标记 truncated。保留前 32 条输入中的最多 16 条，每附件最多两个不同来源，紧凑 UTF-8 JSON 不超过 4096 字节。整数边界拒绝 bool 与 float；未知读取长度保持 null。

1.3 可选诊断被丢弃不影响原文字、可用附件、失败标记和失败附件总数。首源失败、次源成功的两条诊断可以共存，不能据此把成功附件计为失败；该计数仍由公共接收层产生。未知属性不进入 stdout、摘要或私有会话。

1.4 这里只实现适配器的传输白名单，不重复公共下载/分类业务，也不导入旧公共包没有的新模块。旧 inbox 没有该字段和旧私有会话继续兼容。root 对 prompt 仅补诊断语义说明：字节数不是图片像素或 AES 根因，诊断不默认堆入普通微信回复。
