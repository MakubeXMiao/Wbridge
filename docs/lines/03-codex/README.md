# Codex 桥

适配使用 app-server 双向协议，提供显式会话、结果校验、一次性命令/文件修改审批及取消/超时处理，接入公共 v1 后端契约。

1. 从本公开仓库的完整版本安装，按[公共启动指南](../01-core/QUICKSTART-V1.md)确认公共 CLI 和调度。适配器单独的协议测试不能代替完整集成验收。
2. 按[本机测试准备](LOCAL-TESTING.md)准备独立目录、认证、扫码绑定、配置和预检。首次绑定前把配置模板放在运行根之外，扫码成功后才写 `state/backends.json`。
3. 查看[实现与限制](IMPLEMENTATION.md)、[配置模板](backends.example.json)和[测试启动修正背景](APPROVAL-FIXTURE-20261029.md)。这些说明包含当时验证过的固定 CLI 版本；其他版本须重新核对协议。

真实模型生成、审批往返、sandbox、续聊、取消及手机收发须在实际宿主分别验收。离线协议测试与配置预检不代表真实接通。本版不提供已经验证的 Dot / PEPE 常驻云部署；本机路径和登录不能直接搬到另一云主机。当前整体状态见[更新说明](../../PUBLIC-UPDATE-20261029.md)。

[早期接口调查](INTERFACE-REQUIREMENTS.md)仅保留历史背景，不作为当前安装指南。
